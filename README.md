# RADIOCOMUNICATION BBC MICROBIT

> Open this page at [https://cepels-code.github.io/RADIOCOMUNICATION_BBC_MICROBIT/](https://cepels-code.github.io/RADIOCOMUNICATION_BBC_MICROBIT/)

A two-way radio alphabet transceiver for **BBC micro:bit V2** written in MakeCode TypeScript.

## Controls

* **Button B:** Move forward in the alphabet (`A` → `B` → `C`)
* **Gold Touch Logo:** Move backward in the alphabet (`C` → `B` → `A`)
* **Button A:** Transmit selected letter via radio
* **Buttons A+B:** Clear both local and remote LED displays

## Use as Extension

This repository can be added as an **extension** in MakeCode.

* Open [https://makecode.microbit.org/](https://makecode.microbit.org/)
* Click on **New Project**
* Click on **Extensions** under the gear icon menu
* Search for **https://github.com/cepels-code/RADIOCOMUNICATION_BBC_MICROBIT** and import

## Edit this project

To edit this repository in MakeCode:

* Open [https://makecode.microbit.org/](https://makecode.microbit.org/)
* Click on **Import** and then **Import URL**
* Paste **https://github.com/cepels-code/RADIOCOMUNICATION_BBC_MICROBIT** and click import
